# Medical Practice CRM – Project Documentation

This repository contains documentation and design assets for the Medical Practice CRM system.

## Project Overview
The Medical Practice CRM is designed to assist medical practices with:
- Patient management
- Appointment scheduling
- Staff administration
- Clinical workflows
- Secure document storage

The project follows a structured UI/UX workflow from low-fidelity wireframes to high-fidelity prototypes and implementation planning.
