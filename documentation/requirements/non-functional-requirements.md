# Non-Functional Requirements – Medical Practice CRM

## Performance
- The system should respond to user requests within an acceptable time.
- The system should efficientlyently handle multiple users simultaneously.

## Security
- The system must require user authentication before access is granted.
- Sensitive patient information must be securely stored and protected.
- User roles and permissions must restrict unauthorized access.

## Usability
- The interface should be simple, organized, and easy to navigate.
- The system should maintain consistency across all pages.

## Reliability
- The system should minimize downtime and maintain data integrity.
- The system should prevent data loss during normal operation.

## Maintainability
- The project should use modular and organized code structures.
- The system should allow future updates and feature expansions.

## Compatibility
- The system should function on modern web browsers.
- The interface should support responsive layouts for different screen sizes.
