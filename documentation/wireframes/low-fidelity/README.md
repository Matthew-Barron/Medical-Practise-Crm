# Medical Practice CRM – Low-Fidelity Wireframes

This folder contains the low-fidelity wireframes for the Medical Practice CRM system.

## Included Wireframes
- Appointment Scheduler
- Clinical Workspace
- Document Vault
- Patient Directory
- Staff Management

## Purpose
These wireframes were created during the planning and design phase of the project to establish:
- Layout structure
- Navigation flow
- User interface organization
- Core feature placement
- Dashboard and management functionality

## Design Process
The project follows a progressive UI/UX workflow:
1. Low-Fidelity Wireframes
2. Mid-Fidelity Designs
3. High-Fidelity Mockups

The low-fidelity designs focus on functionality, layout planning, and information hierarchy before visual styling and refinement.
